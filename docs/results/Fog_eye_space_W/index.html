Fog_eye_space_W

Description
Tests fixed function fog generation when the eye-space position has a w component other than 1.0.
A model view matrix whose w column is not (0, 0, 0, 1) (e.g., a planar projected shadow matrix folded into the world transform) or a vertex position with w != 1 produces a homogeneous eye-space position. The screen position is unaffected since the composite matrix and perspective divide cancel the scale, but the fog distance may or may not be computed from the dehomogenized position.
Reproduces
https://github.com/xemu-project/xemu/issues/3135
(Hunter: The Reckoning - Redeemer shadows rendered in the fog color).
Each test draws a series of horizontal strips. Every strip covers the same screen area at the same eye-space depths (3.0 at the left edge to 40.0 at the right) and the composite matrix is never altered, so only the eye-space position used for fog generation differs between strips. The first strip is the w = 1 reference. Strips blend from a dark diffuse color toward a yellow fog color.
Observations from HW:
The eye-space position is divided by its w component before fog generation in planar, absolute planar, and radial modes. Uniformly scaling the model view matrix or the vertex position (including by a negative value) has no effect on fog, while altering only the eye-space w changes the fog distance to (eye.xyz / eye.w).
Eye-space w of +0 and -0 behave identically. For planar and absolute planar generation the result matches a very large negative distance (no fog in linear and exp modes, full fog in exp2). For radial generation the result matches a distance of 0 (no fog in every mode).
An eye-space position of (0, 0, 0, 0) produces no fog in every mode.
Absolute planar generation does not discard the sign of a tiny negative w (-1e-6 matches planar, not radial).

MVProjective-abs_planar-exp

Exponential absolute planar fog. The model view w column is modified so eye w = 1 + a * eye_x while eye xyz are unchanged; a = 0 is the reference. The fog distance is divided by eye w, so positive a reduces fog right of the screen center (where eye_x > 0) and slightly increases it left of center; negative a does the opposite.

MVZeroW-abs_planar-exp

Exponential absolute planar fog. The model view w column is replaced with (0, 0, 0, w) so eye xyz are unchanged and eye w is 1 (reference), +0, -0, 1e-6, or -1e-6. The final strip zeroes the entire matrix so eye position is (0, 0, 0, 0). The w 1e-6 strip is entirely fogged. The w 0, w -0, w -1e-6, and w 0 xyz 0 strips are entirely unfogged (w 0 behaves like a large negative distance). Despite the absolute value gen mode, the sign of w is not discarded.
