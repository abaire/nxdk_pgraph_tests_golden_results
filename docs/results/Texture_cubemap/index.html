CubemapZeroVector

Renders screen-space quads point sampling a cubemap with a constant texture coordinate per quad. Every texel has a unique color that encodes its face and position: R = x * 4 + 2, G = y * 4 + 2, B = face * 40 + 20, with faces ordered +X, -X, +Y, -Y, +Z, -Z. The exception is texel (0, 0) of the +X face, which is pure magenta. The large quads use zero length directions: (0, 0, 0, 1), (0, 0, 0, 0), and (-0, -0, -0, 1). The small quads below them are a self check of the texel encoding, sampling the +/-X, +/-Y, and +/-Z axis directions in pairs.

CubemapZeroVectorAddressModes

Renders 44x44 screen-space quads sampling the 4 level mipmapped cubemap described in CubemapZeroVectorMipmap_Point in stage 3 using PS_TEXTUREMODES_CUBEMAP. Every quad has the texture coordinate (0, 0, 0, 1) at every vertex. For every quad the P wrap mode is WRAP_CLAMP_TO_EDGE, the MIN_LOD_CLAMP raw value is 0, the MAX_LOD_CLAMP raw value is 0xFFF, the MIPMAP_LOD_BIAS is 0, the convolution kernel is K_QUINCUNX, anisotropy is 1, and the border source is NV097_SET_TEXTURE_BORDER_COLOR with the value 0xFFFF0000. The left block of quads uses MIN_TENT_TENT_LOD with MAG_TENT_LOD0. Left to right, its columns use the address mode WRAP_REPEAT ("WRAP"), WRAP_MIRROR ("MIRR"), WRAP_CLAMP_TO_EDGE ("CLMP"), WRAP_BORDER ("BRDR"), and WRAP_CLAMP_TO_EDGE_OGL ("OGL"). The right block of quads uses MIN_BOX_NEARESTLOD with MAG_BOX_LOD0. Left to right, its columns use WRAP_MIRROR ("MIRR"), WRAP_BORDER ("BRDR"), and WRAP_CLAMP_TO_EDGE_OGL ("OGL"). Top to bottom, the rows of both blocks set U to the column's address mode with V WRAP_CLAMP_TO_EDGE ("U=m"), U WRAP_CLAMP_TO_EDGE with V set to the column's address mode ("V=m"), and both U and V set to the column's address mode ("UV=m").

CubemapZeroVectorConvolution

Renders 44x44 screen-space quads sampling the 4 level mipmapped cubemap described in CubemapZeroVectorMipmap_Point in stage 3 using PS_TEXTUREMODES_CUBEMAP. Every quad has the texture coordinate (0, 0, 0, 1) at every vertex. For every quad the MIN_LOD_CLAMP raw value is 0, the MAX_LOD_CLAMP raw value is 0xFFF, the MIPMAP_LOD_BIAS is 0, anisotropy is 1, and the border source is NV097_SET_TEXTURE_BORDER_COLOR with the value 0xFFFF0000. Left to right, the columns use MIN_CONVOLUTION_2D_LOD0 with MAG_CONVOLUTION_2D_LOD0 and the K_QUINCUNX kernel ("CCQ"), MIN_CONVOLUTION_2D_LOD0 with MAG_CONVOLUTION_2D_LOD0 and the K_GAUSSIAN_3 kernel ("CCG"), MIN_CONVOLUTION_2D_LOD0 with MAG_BOX_LOD0 ("CB"), MIN_CONVOLUTION_2D_LOD0 with MAG_TENT_LOD0 ("CT"), MIN_BOX_NEARESTLOD with MAG_CONVOLUTION_2D_LOD0 ("BNC"), and MIN_TENT_TENT_LOD with MAG_CONVOLUTION_2D_LOD0 ("TTC"). The last four use the K_QUINCUNX kernel. The U, V, and P wrap modes of the top row ("WRAP") are WRAP_REPEAT and of the bottom row ("CLMP") are WRAP_CLAMP_TO_EDGE.

CubemapZeroVectorMipmap_Point

Renders screen-space quads sampling a 64x64 A8B8G8R8 cubemap with 4 mipmap levels (64, 32, 16, 8) in stage 3 using PS_TEXTUREMODES_CUBEMAP. The filter is MIN_BOX_NEARESTLOD with MAG_BOX_LOD0, and the U, V, and P wrap modes are WRAP_CLAMP_TO_EDGE. Colors are given as ARGB. On the +X face, every texel of level 0, 1, 2, 3 is 0xFF0000A0, 0xFF00A000, 0xFFA00000, 0xFFA0A0A0 respectively, except for: texel (0, 0), which is 0xFFFF00FF, 0xFF00FFFF, 0xFFFFFF00, 0xFFFFFFFF on level 0, 1, 2, 3; texel (1, 0), which is 0xFFFF8000; texel (0, 1), which is 0xFF8000FF; texel (1, 1), which is 0xFF00FF80; the last column, which is 0xFF000000; the last row, which is 0xFF808000; and the last texel of the last row, which is 0xFF008080. Every texel of every level of the other faces is a single color per face: -X 0xFF603030, +Y 0xFFFF80C0, -Y 0xFF306030, +Z 0xFF80C0FF, -Z 0xFF303060.

DotReflectSpecZeroVector

Renders screen-space quads using PS_TEXTUREMODES_DOT_RFLCT_SPEC on stage 3 (stage 0 is 2D projective, stages 1 and 2 are PS_TEXTUREMODES_DOT_PRODUCT), point sampling a cubemap in stage 3. The cubemap texel encoding, dot RGB mapping, and stage 0 texture are the same as in DotSTRCubeZeroVector. The normal is N = (dot1, dot2, dot3) and the eye vector is E = (T1.w, T2.w, T3.w). The cube direction is R = 2 * N * dot(N, E) / dot(N, N) - E. NV097_SET_EYE_VECTOR is (0, 0, 0). The large quads, left to right, use N = (0, 0, 0) with E = (0, 0, 0), N = (0, 0, 0) with E = (1, 0, 0), N = (0, 0, 0) with E = (0, 0, 1), and N = (1, 1, 0) with E = (0, 1, 0), which reflects to (1, 0, 0). The small quads below them are a self check of the texel encoding. Each has N = +X, +Y, or +Z and E = +/-N so that R is +/-X, +/-Y, or +/-Z, in pairs.

DotSTRCubeZeroVector

Renders screen-space quads using PS_TEXTUREMODES_DOT_STR_CUBE on stage 3 (stage 0 is 2D projective, stages 1 and 2 are PS_TEXTUREMODES_DOT_PRODUCT), point sampling a cubemap in stage 3. The cubemap texel encoding is the same as in CubemapZeroVector. NV097_SET_DOT_RGBMAPPING is set to dotmap_zero_to_one for all stages. Stage 0 is a 4x4 texture of constant color 0xFFFFFFFF, so the dot products are dot(Ti.xyz, (1, 1, 1)). Each large quad has constant texture coordinates and the xyz components of stages 1-3 are all 0, so (dot1, dot2, dot3) = (0, 0, 0). The w components of stages 1-3 differ per quad: (0, 0, 0), (1, 1, 1), and (-1, 0.5, 2). NV097_SET_EYE_VECTOR is (0, 0, 0). The small quads below them are a self check of the texel encoding. Each sets a single xyz component of one stage to +/-1 and the rest to 0 so that (dot1, dot2, dot3) is +/-X, +/-Y, or +/-Z, in pairs.
