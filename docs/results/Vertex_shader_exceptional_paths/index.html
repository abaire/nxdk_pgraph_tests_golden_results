Vertex_shader_exceptional_paths

Description
Renders MAC results with operand A from the v1 attribute (Attr_ tests) or a constant (Const_ tests), and the fog distance chain rcp(P.w), P * rcp(P.w), d2 = DP3, rsq(d2), d2 * rsq(d2) with P from v1 or a constant. Hardware gives identical results on both paths. The layout is described in
VertexShaderExceptionalMACTests
.
